# Code of conduct

DiskPilot is a small open-source project. We keep collaboration simple:

- **Be kind and be specific.** Critique code and ideas, not people.
  Assume good faith; ask before concluding.
- **Stay on topic.** Issues and pull requests are for the product:
  bugs, safety, features, docs.
- **No harassment.** Harassment, discrimination, personal attacks and
  publishing someone's private information are not tolerated in any
  project space, public or private.
- **Respect the safety culture.** Work that weakens the safety model —
  even "for convenience" — will be declined, and that's not personal.

Maintainers may edit, close or remove contributions, and may restrict
participation, for behaviour that breaks these rules. If you experience
or witness a problem, contact the maintainers privately through the
repository owner's profile. Reports are handled confidentially.
